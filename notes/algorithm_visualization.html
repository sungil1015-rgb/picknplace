현행 운영 상태 (2026-06-19 갱신)
아래 도식의 layer 수치(L5/L7/L8)·mango fusion은 base 시절 분석 기준이다. 현재 운영은 → DINOv2-large(dim 1024) · 전 클래스 dinov2_layer=12 통일, mango(젤리껌)는 fusion 아닌 plain patchcore로 운영(enabled)하며 정량 TPR 검증은 보류 상태, 임계는 보수적(τ=max(F1-best, 정상 p99.5) — 비닐 정상 구겨짐 오거부 방지), 나머지는 weights/defect_thresholds.json으로 자동 적용(없으면 fail-loud). 로직(PatchCore/Cascade/다수결, 분류↔결함 layer 분리)은 동일.

FIGURE NOTES — 발표 시 정확성 유의

  • 두 그림의 점선/빨강 요소는 "현재 동작"이 아니라 설계됨·미검증·staged 상태다. (캐시 재사용·pick_n_place 배선·mango fusion·layer 전환)
  • layer 번호(L5/L7/L8)는 dinov2-base 기준이다. large(24 block) 전환 시 전부 재-ablation 필요(이론 예측 밴드 L10–16).
  • 수치(AUROC·τ·μ/σ)는 base·합성결함·LOO 기준 산출값으로, 실물 로봇 테스트 false rate로 재검증 대상이다.
