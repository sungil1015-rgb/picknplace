# mango 결함탐지 전방위 정량평가 보고서

작성: 2026-06-12. 대상: bank v2 (오염 정제, 309 obj) + PatchCore max (L8) + 비율 tear 벤치마크.
테스트 9종 + layer ablation. 모든 score는 strict LOO. 기준 운영점 τ_ref = 8.72 (p95).

---

## TL;DR

> **기본 성능 AUROC 0.885 (95% CI 0.850~0.917), 탐지 한계는 tear 크기 ~3%.**
> 결함 종류 커버리지는 양호 (scratch/구멍/얼룩 0.92~0.99).
> **배포 최대 리스크는 결함 탐지력이 아니라 신규 촬영 세션 FPR 폭증 (21~40%)과 글레어 (FPR 44%)** — 두 가지 모두 운영 절차로 통제 가능.
> layer는 mango에서 L8이 최적 (현행 유지 근거 확보), 전 클래스 통합 전환 시 L7이 유일 후보.

## 1. 기본 성능 (변경 없는 조건)

| 항목 | 값 | 비고 |
|---|---|---|
| AUROC (tear 3~7%, max) | **0.885** | bootstrap 95% CI [0.850, 0.917] (객체 단위 1000회) |
| TPR @ FPR 5% | 0.74 | τ = 8.72 (p95) |
| 객체당 지연시간 | **24.5 ms** (p95 25.9) | A5000 단독. 예산 16~30ms 충족. 4080은 동급~1.2x 추정 |
| 전수 정상 통계 (309) | mu 8.54, p95 **8.97**, median ~8.0 | tail 4개 잔존 (글레어 132.9, 뒷면 25.9, 구김 16.8×2) — CV 0.851은 여전히 tail이 지배 |

주의: yaml의 pc_mu 7.95 / pc_sigma 1.18은 80샘플 기준 (tail 미포함이라 z-정규화엔 오히려 적합). 전수 sigma 7.26은 tail 오염값이므로 사용 금지.

## 5. LOSO (세트 제외 교차) — 배포 최대 리스크

bank에 없는 촬영 세션의 정상 객체 평가 (신규 세션 시뮬):

| 제외 세트 | n | FPR @ τ=8.72 | AUROC |
|---|---|---|---|
| 0424_2조 | 12 | **33%** | 0.788 |
| 0508_1조 | 87 | **21%** | 0.845 |
| 0508_2조 | 31 | **23%** | 0.917 |
| 0515 | 179 | **40%** | 0.785 |

**bank에 현재 세션이 없으면 FPR이 4~8배 폭증.** H2에서 발견한 세션 시그니처의 정량 확인. LOO 평가 수치 (FPR 5%)는 같은 세션이 bank에 있다는 가정 하의 값.

**운영 수칙 (필수)**: 새 촬영 세션 시작 시 정상 객체 수십 장을 bank에 추가 후 가동. 또는 세션 워밍업 단계에서 τ 재캘리브.

## 7.5 Multi-layer 결합 (사용자 제안: "4, 8, 12 레이어를 같이")

표기 주의: 모델 block 12개, 우리 표의 **L11 = 마지막 block = classifier가 쓰는 layer** (사용자의 "12번"). forward 1회에 전 layer가 나오므로 추가 forward 비용 0. layer 간 거리 스케일 ~18배 차 (s_L: L4 1.4 / L8 6.0 / L11 24.9) → per-layer 정규화 후 결합 필수.

결합 방식: (a) patch-level — patch별 정규화 거리 평균 후 max (concat 근사), (b) score-level — 객체 score의 z 평균. **(a)가 전 조합에서 우월.**

| 조합 (patch-level) | mango_v2 | haribo |
|---|---|---|
| L8 단일 (현행) | 0.870 | 0.883 |
| L4+L8 | 0.873 | **0.904** |
| L8+L11 | 0.882 | 0.854 |
| L4+L11 | 0.878 | 0.876 |
| **L4+L8+L11** | **0.888** (TPR@5% 0.66→0.72) | 0.894 (TPR 0.50 하락) |

판정:
- **mango: L4+L8+L11이 최선** (+0.018, TPR@FPR5% +6pp) — 사용자 제안 그대로 채택 가치. 단 CI (±0.03) 안의 개선이라 단독 근거로는 약하고, TPR 개선이 일관된 점이 가산점
- **haribo: L11이 해롭다** (L8+L11 0.854 < L8 단일 0.883) — deformable은 semantic layer가 노이즈. haribo 최선은 L4+L8 (0.904)... 인데 **단일 L7 (0.913)이 그마저 이김**
- 교훈: multi-layer가 만능이 아니라 클래스 특성 의존. mango는 결합 이득, haribo는 좋은 단일 layer (L7)가 더 나음
- 비용: bank 3배 (mango 100→300MB), NN 3배 (24.5ms → 약 30ms 추정, 예산 내)

권장: mango에 한해 L4+L8+L11 patch-level 결합 채택 검토 (실물 검증 통과 후). haribo는 L7 단일 전환이 더 큰 이득.

## 8. 종합 결론 + 액션

### 결론
1. RGB 채널 (PatchCore max, L8)은 tear ≥3%에서 신뢰 가능 (CI 하한 0.85), 기타 결함 (scratch/구멍/얼룩)은 더 잘 잡음
2. 결함 탐지력보다 **운영 변수 (신규 세션, 글레어, 느슨한 mask)가 실 FPR을 지배** — 모두 절차로 통제 가능
3. 통계 (max)와 layer (L8)는 현행이 mango 최적 — 변경 불요

### 액션 (우선순위)
1. **[운영 수칙 제정] 신규 세션 → bank 보강 후 가동** (LOSO 근거 — 가장 중요)
2. [로봇 테스트] 실물 찢김 1~2봉지 (Laplacian TPR — 탐지한계 3% 이하 영역 검증 겸)
3. [로봇 테스트] 운영 Mask2Former mask로 FPR 측정 (폴리곤 라벨과의 괴리 확인 — mask_dilate 21% 리스크)
4. [bank 보강] 글레어 강한 포즈 정상 샘플 추가 수집 (FPR 44% → 완화)
5. [후속] 전 클래스 L7 통합 전환 검토 (haribo +0.030 이득)
